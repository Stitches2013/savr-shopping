# SAVR Search — Version 3

A browser-based shopping prototype with local example listings and direct live search links for Amazon, Target, Walmart, and DICK'S Sporting Goods. Submit any search term, then choose a retailer button to see current products, prices, and availability in that store's catalog. Product photos and retailer links are also included for selected eyewear from EyeBuyDirect, Oakley, Blenders Eyewear, and Ray-Ban.

The four stores' complete catalogs are too large and dynamic to copy into a static website. SAVR opens each retailer's own live search results because this prototype has no retailer product API or feed credentials. Other SAVR catalog entries are sample data; verify price and availability with the store.

Open `index.html` directly, or run `python3 -m http.server 8000` from this directory and visit <http://localhost:8000>.
